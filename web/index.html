STEP 01

Discover

Search across every connected supplier at once — products, live availability and real prices, in one place.

STEP 02

Hold

Reserve a slot. Capacity is held while you decide. Nothing is charged, and the reservation can't be duplicated.

STEP 03

Approve & confirm

The booking is only confirmed — and only charged — after a person explicitly says yes. The agent can never spend on its own.

№ 04 — Take it with you

Add OCTO to your AI.

The chat above isn't a toy — it's a live Model Context Protocol server. Paste one URL into your own assistant and it gets the same booking tools: search, hold, and confirm — with you approving every charge.

Endpoint https://octo.mytrip.ai/mcp
CHATGPT

Settings → Connectors

Create a connector, paste the URL, save — then ask it to book a tour. (Needs a plan with custom connectors / developer mode.)

CLAUDE

Settings → Connectors

Choose “Add custom connector” and paste the URL. Works in both Claude.ai and the Claude desktop app.

CURSOR · WINDSURF · VS CODE

Add a remote MCP server

Point a remote / Streamable-HTTP MCP server at the URL above. No install, no keys.

Claude Code · terminal

claude mcp add --transport http octo https://octo.mytrip.ai/mcp
